# 头像图标说明

## 需要添加的图标文件

请将以下图标文件添加到 `images/` 目录下：

### 1. avatar.png
- 尺寸：81px × 81px
- 用途：TabBar中的默认头像图标
- 建议：使用简单的用户头像图标，可以是圆形头像

### 2. avatar-selected.png  
- 尺寸：81px × 81px
- 用途：TabBar中被选中时的头像图标
- 建议：与avatar.png相同，但可以有选中状态的视觉效果（如边框高亮）

## 图标规范

- **格式**: PNG格式
- **尺寸**: 81px × 81px（微信小程序TabBar图标标准尺寸）
- **背景**: 透明背景
- **风格**: 简洁明了，与应用整体设计风格一致

## 临时解决方案

如果没有头像图标，可以：
1. 使用系统默认图标
2. 从app.json中移除iconPath配置，只保留文字
3. 使用在线图标生成工具创建简单头像
